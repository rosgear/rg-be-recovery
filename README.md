## <img src="https://raw.githubusercontent.com/rosgear/rg-be-recovery/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Модуль «Восстановление доступа к аккаунту»

Модуль входит в состав Панели управления GePanel.

Модуль предназначен для восстановления учётных записей пользователей Панели управления GePanel, включая сброс паролей и восстановление доступа при утрате учётных данных.

### Установка

Для добавления модуля в ваш проект, вы можете просто выполнить команду ниже:

```
$ composer require rosgear/rg-be-recovery
```

или добавить в файл composer.json вашего проекта:
```
"require": {
    "rosgear/rg-be-recovery": "*"
}
```
или скачать архив на [странице модуля](https://rosgear.ru/component/rg-be-recovery/) в каталоге приложений RosGear.

После добавления модуля в проект выполните его установку в редакцию веб‑приложения с помощью Панели управления GePanel.

<a name="english"></a>
## <img src="https://raw.githubusercontent.com/rosgear/rg-be-recovery/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Module «Account recovery»

The module is part of the GePanel Control Panel.

This module is designed to restore user accounts for the GePanel Control Panel, including resetting passwords and restoring access if credentials are lost.

### Installation

To add the module to your project, you can simply run the command below:

```
$ composer require rosgear/rg-be-recovery
```

or add to your project's composer.json file:
```
"require": {
    "rosgear/rg-be-recovery": "*"
}
```
or download the archive from the [module page](https://rosgear.ru/component/rg-be-recovery/) in the RosGear application catalog.

After adding the module to the project, install it into the web application edition using the GePanel Control Panel.
